# Final Scientific Reports revision

This directory contains the complete final revision of **An Accuracy and Calibration Benchmark of scGPT Pipelines and Matched Classical Models for Cell Type Annotation**.

- `manuscript_clean.pdf`: clean line-numbered manuscript
- `manuscript_marked.pdf`: marked manuscript
- `supplementary_information.pdf`: Supplementary Information
- `response_to_reviewers.pdf`: point-by-point response
- `cover_letter.pdf`: revision cover letter
- `source/`: complete compilable LaTeX source and publication figures

The manuscript is 23 pages and its abstract is 195 words. The primary analysis contains three complete donor-held-out human atlases; pig pancreas is reported only as a separate stress test.
