# Final Scientific Reports submission materials

This directory contains the complete final revision of **An Accuracy and Calibration Benchmark of scGPT Pipelines and Matched Classical Models for Cell Type Annotation**.

- `manuscript_clean.docx`: clean line-numbered Word manuscript
- `manuscript_tracked_changes.docx`: Word manuscript with focused Track Changes
- `manuscript_clean.pdf` and `manuscript_tracked_changes.pdf`: visual proof copies
- `supplementary_information.pdf`: Supplementary Information
- `response_to_editor_and_reviewers.docx` and `.pdf`: point-by-point response with exact line references
- `cover_letter.docx` and `.pdf`: dated cover letter with affiliations
- `latex_source.zip`: unified publication-facing LaTeX source package
- `source/`: unpacked LaTeX source and publication figures

The primary analysis contains three complete donor-held-out human atlases; pig pancreas is reported only as a separate cross-species stress test. The LaTeX source contains a clean manuscript only; the marked revision is supplied in Word so the changes are visible through Track Changes.
