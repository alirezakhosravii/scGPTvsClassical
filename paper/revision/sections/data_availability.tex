\section{Data availability}

All datasets are publicly available through CZ CELL$\times$GENE Discover. The collection page supplies publication and metadata context; the paired explorer link identifies the exact object analysed.
\begin{itemize}
\item TNBC breast cancer: \url{https://cellxgene.cziscience.com/collections/ceef2841-5333-46ac-92ef-ccbe0c20fe55}; exact dataset \url{https://cellxgene.cziscience.com/e/6f9de485-58cd-4342-bfc4-b3d3dd223aa8.cxg/}.
\item Indonesia PBMC: \url{https://cellxgene.cziscience.com/collections/d1e0e64d-6d2a-4a3e-b7f4-43ed909a9d9c}; exact dataset \url{https://cellxgene.cziscience.com/e/ca7d95ac-53aa-4a94-8c76-300c608ce6a0.cxg/}.
\item Brain atlas: \url{https://cellxgene.cziscience.com/collections/0986e4cd-7a58-405d-9b91-4b199bb4124e}; exact dataset \url{https://cellxgene.cziscience.com/e/e2a00644-0a48-4815-ae87-d562045114f5.cxg/}.
\item Multi-tissue TME: \url{https://cellxgene.cziscience.com/collections/3f7c572c-cd73-4b51-a313-207c7f20f188}; exact dataset \url{https://cellxgene.cziscience.com/e/b617ee1b-f8c8-4de9-b82b-e803ab93550d.cxg/}.
\item Human pancreas: \url{https://cellxgene.cziscience.com/collections/0a77d4c0-d5d0-40f0-aa1a-5e1429bcbd7e}; exact dataset \url{https://cellxgene.cziscience.com/e/3294d050-6eeb-4a00-b24c-71aacc9b777f.cxg/}.
\item Pig pancreas: \url{https://cellxgene.cziscience.com/collections/0a77d4c0-d5d0-40f0-aa1a-5e1429bcbd7e}; exact dataset \url{https://cellxgene.cziscience.com/e/db4a9ed2-e994-40c1-b7ec-4091fdf7b6c1.cxg/}.
\end{itemize}

The released whole-human scGPT checkpoint is available from the scGPT authors at \url{https://github.com/bowang-lab/scGPT}. Data and checkpoint identities are independently recorded by stable dataset UUIDs and SHA-256 hashes in the computational audit. Summary tables, reliability-bin data, bootstrap results, and executable analysis code are included in the submission package and the public repository at \url{https://github.com/alirezakhosravii/scGPTvsClassical}. Raw H5AD objects, per-cell prediction archives, and pretrained weights are not duplicated because of their size and existing public availability.
